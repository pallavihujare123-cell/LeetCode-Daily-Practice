DAY 03 — ADD TWO NUMBERS

🧩 Problem
You are given two non-empty linked lists representing two non-negative integers.
The digits are stored in reverse order. Add the two numbers and return the sum as a linked list.

Example:
Input:
l1 = [2,4,3]
l2 = [5,6,4]

Output:
[7,0,8]

Because:
342 + 465 = 807
The result is stored in reverse order:
807 → [7,0,8]

2. HOW THE PROBLEM WORKS
| Step | What Happens                                     |
| ---- | ------------------------------------------------ |
| 1️⃣  | Take the current digit from l1                   |
| 2️⃣  | Take the current digit from l2                   |
| 3️⃣  | Add both digits and the carry                    |
| 4️⃣  | Store the last digit in the result               |
| 5️⃣  | Calculate the carry                              |
| 6️⃣  | Move to the next nodes                           |
| 7️⃣  | Continue until both lists and carry are finished |

Example:
l1 = [2,4,3]
l2 = [5,6,4]

2 + 5 = 7
4 + 6 = 10 → store 0, carry 1
3 + 4 + 1 = 8

Result:
[7,0,8]

3. CONCEPTS USED

| Concept      | Definition                           | Syntax / Example         | Important Point                   |
| ------------ | ------------------------------------ | ------------------------ | --------------------------------- |
| Linked List  | Collection of connected nodes        | l1.next                  | Each node points to the next node |
| Node         | Stores a value and next reference    | ListNode(2)              | Contains value and next           |
| Variable     | Stores a value in memory             | carry = 0                | Value can change                  |
| while loop   | Repeats while condition is true      | while l1 or l2 or carry: | Processes all required nodes      |
| carry        | Value passed to the next addition    | carry = total // 10      | Used when sum is 10 or more       |
| //           | Floor division                       | total // 10              | Gets the carry                    |
| %            | Modulus                              | total % 10               | Gets the current digit            |
| if statement | Executes code when condition is true | if l1:                   | Checks whether a node exists      |

4. IMPORTANT SYNTAX

| Syntax                         | Meaning                            |
| ------------------------------ | ---------------------------------- |
| ListNode(0)                    | Creates a new linked list node     |
| l1.val                         | Gets the current value of l1       |
| l1.next                        | Moves l1 to the next node          |
| x = l1.val if l1 else 0        | Gets value or uses 0 if list ended |
| total = x + y + carry          | Adds both digits and carry         |
| carry = total // 10            | Calculates the carry               |
| digit = total % 10             | Gets the current digit             |
| current.next = ListNode(digit) | Adds a new result node             |
| current = current.next         | Moves to the next result node      |


5. COMPLEXITY

| Type             | Complexity  | Meaning                            |
| ---------------- | ----------- | ---------------------------------- |
| Time Complexity  | O(max(n,m)) | Each linked list is traversed once |
| Space Complexity | O(max(n,m)) | Result linked list is created      |
