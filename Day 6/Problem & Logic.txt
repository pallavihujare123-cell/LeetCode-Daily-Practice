# 🚀 Day 06 — Add Digits

## 🧩 Problem
Given an integer `num`, repeatedly add all its digits until the result has only one digit.
### Example
**Input:**
38


**Process:**

3 + 8 = 11
1 + 1 = 2


**Output:**
2


## 🧠 Logic

1. Check if the number has more than one digit.
2. Extract the last digit using `% 10`.
3. Add the digit to `total`.
4. Remove the last digit using `// 10`.
5. Repeat until only one digit remains.
6. Return the final single digit.

---

## 🔍 Example Dry Run

For:

num = 38
```

### Step 1

38 % 10 = 8
38 // 10 = 3
```

### Step 2

3 % 10 = 3
3 // 10 = 0
```

So:

8 + 3 = 11


Now repeat:

1 + 1 = 2


Final answer:
2



## 💻 Solution

```python
class Solution:
    def addDigits(self, num):
        while num >= 10:
            total = 0

            while num > 0:
                total += num % 10
                num //= 10

            num = total

        return num
```

## 📚 Concepts Used

| Concept      | Meaning                | Example           |
| ------------ | ---------------------- | ----------------- |
| `% 10`       | Extract last digit     | `38 % 10 = 8`     |
| `// 10`      | Remove last digit      | `38 // 10 = 3`    |
| `while` loop | Repeat operation       | `while num >= 10` |
| Variable     | Store calculated value | `total = 0`       |

## ⭐ Important Points

Used to get the last digit.

```

### `// 10`

Used to remove the last digit.

```python

```

```text

```

## 🎯 Interview Questions

### 1. What does `% 10` do?

It extracts the last digit of a number.

### 2. What does `// 10` do?

It removes the last digit of a number.

### 3. Why do we use a `while` loop?

Because we need to repeatedly add the digits until only one digit remains.
